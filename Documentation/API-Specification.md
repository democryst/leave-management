# API Specification v1.0

## 🛡️ Authentication
All API calls (except health checks) require a Bearer Token.
- **Edge Token:** Provided by the Identity Provider to the Frontend.
- **Internal Service Token (IST):** Generated by the Gateway using RS256.

---

## 🛰️ API Gateway (Port 8080)

### GET /api/v1/staff/:id
Proxies to the Staff Service. Requires a valid JWT.

---

## 👥 Staff Service (Port 8081)

### GET /api/v1/staff/:id
Retrieves detailed staff information.
- **Response (200 OK):**
```json
{
  "id": "uuid-v7",
  "staff_id": "STF001",
  "full_name": "John Doe",
  "email": "john@example.com",
  "role": "staff",
  "manager_id": "uuid-mgr",
  "created_at": "2024-05-09T..."
}
```

---

## 🏖️ Leave Service (Port 8082)

### POST /api/v1/leave/requests
Applies for a new leave request. Performs atomic balance check.
- **Request Body:**
```json
{
  "staff_id": "uuid-v7",
  "leave_type_id": "uuid-v7",
  "start_date": "2024-06-01",
  "end_date": "2024-06-05",
  "reason": "Family vacation",
  "days": "5.0"
}
```
- **Response (201 Created):** The created LeaveRequest object.
- **Response (400 Bad Request):** `{"error": "Insufficient balance"}`

---

## 📜 Policy Service (Port 8083)

### GET /api/v1/policies/leave-types/:id
Retrieves policy details for a specific leave type.
- **Response (200 OK):**
```json
{
  "id": "uuid-v7",
  "name": "Annual Leave",
  "description": "Standard yearly leave",
  "default_days": 20.0,
  "is_active": true
}
```
